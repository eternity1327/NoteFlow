# AI disclosure

Using AI is allowed in this hackathon. These are all the AI tools we used and what we used them for.

| Tool | Used for |
| --- | --- |
| ChatGPT (OpenAI) | Brainstorming the idea and drafting the project brief and feature list |
| Google Stitch | Designing the UI mockup |
| Claude (Anthropic), in Claude Cowork | Reading the hackathon brief, planning, writing and updating the code (`agent.py`, `composer.py`, `app.py`, `metta/`, `static/`, `tests/`), setting up the online deployment, writing the README, and producing the demo video (screen recording of the real app, motion graphics, music and sound effects generated by code) |
| Kokoro TTS (open-source, Apache 2.0) | The AI-generated voiceover in the demo video |

## What the team did

- Chose the track, the challenge, the idea, the features and the colour palette.
- Designed the screens in Stitch.
- Reviewed, ran and tested the app, locally and online.
- Decided on the changes to the interface and the split sheet.
- Deployed the live demo on Render.
- Reviewed the demo video before submitting.

## AI inside the product

NoteFlow's agent is rule-based. It uses MeTTa (OpenCog Hyperon) to score ideas and learn from feedback. Chords, structures and lyric sketches come from built-in music rules and word lists. It does not call any external AI model or API and does not use any partner data. In the split sheet, the AI's suggestions are disclosed and the AI gets no share.
